# 周末漫游 · Weekend Roam

「周末城市探索指南」——根据**天气、预算与兴趣**推荐本地周末活动，支持**组队出发、打卡记录、攻略分享**。

## 功能

- **首页推荐**：天气感知的活动推荐流，支持类型 / 预算筛选（展览、市集、演出、徒步、手作…）
- **组队广场**：加入或发起组队
- **足迹打卡**：打卡点亮地图、经验值 +10 XP、成就徽章解锁
- **攻略分享**：同城周末攻略，点赞 / 收藏
- **我的**：个人主页、兴趣与预算偏好

## 技术

- 纯静态单文件（`index.html`），零依赖，开箱即用
- 数据内置，交互状态用 `localStorage` 持久化
- 部署于 GitHub Pages
